# NEXUS Intervention Experience

## Product Principle

NEXUS should feel like an intelligent operating layer around the user's productivity.

It should not feel like a notification machine.

The core principle is:

> Help more. Interrupt less.

---

## Intervention Hierarchy

NEXUS prefers the least disruptive intervention that can still provide meaningful value.

```text
1. Silent adjustment
2. Focus protection
3. Dashboard signal
4. Inline suggestion
5. Notification
