NEXUS — Color System

1. Color Philosophy

NEXUS uses a neutral-first color system.

Color is primarily used to communicate:

- state,
- priority,
- action,
- system intelligence,
- and semantic meaning.

Color should not be used purely for decoration.

---

---

5. Primary Accent

NEXUS uses a restrained blue-violet intelligence accent.

Primary:

"#5B5CE2"

Hover:

"#4D4EC8"

Soft background:

"#EEF0FF"

The accent represents:

- primary actions,
- intelligence,
- active states,
- system recommendations.

---

6. Semantic Colors

Success:

"#238636"

Warning:

"#B7791F"

Danger:

"#C53030"

Informational:

"#2563EB"

These colors should be paired with text, icons, or patterns.

Color alone must never communicate meaning.

---

7. AI Accent

AI-generated content should use the primary intelligence accent with subtle visual differentiation.

Avoid:

- rainbow gradients,
- excessive glow,
- animated particles,
- glowing text.

---

8. Color Ratio

The approximate visual distribution should be:

Neutral surfaces       85–90%
Text / structure       8–12%
Accent / semantic      2–5%

This keeps the product sophisticated and prevents visual fatigue.

---

9. Dark Mode

Dark mode should not simply invert the light palette.

It should use:

- deep neutral surfaces,
- controlled contrast,
- muted borders,
- reduced saturation.

The goal is a professional workspace rather than a gaming interface.
