NEXUS — Typography System

1. Typography Philosophy

Typography is one of the primary mechanisms through which NEXUS communicates hierarchy.

The system should feel:

- precise,
- contemporary,
- highly legible,
- technically sophisticated.

---

2. Font Families

UI

Inter

Used for:

- navigation,
- buttons,
- labels,
- forms,
- tables,
- system information.

Display

Manrope

Used selectively for:

- major page headings,
- product statements,
- important numerical moments.

4. Numerical Typography

Productivity metrics should use tabular numerals where appropriate.

Examples:

06:42:18
5h 20m
78%
14 tasks

Numerical alignment is important for dashboards and analytical interfaces.

---

5. Hierarchy Principle

Do not create hierarchy solely through font size.

Hierarchy may also use:

- weight,
- spacing,
- contrast,
- position,
- grouping.

This reduces the need for oversized typography.
