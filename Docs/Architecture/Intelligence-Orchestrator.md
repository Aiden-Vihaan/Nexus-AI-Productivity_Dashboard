# NEXUS Intelligence Orchestrator

## Purpose

The Intelligence Orchestrator coordinates the intelligence pipeline.

It determines:

- What context is required
- Which deterministic systems must run
- Which candidate actions are valid
- When AI reasoning is appropriate
- How recommendations are validated
