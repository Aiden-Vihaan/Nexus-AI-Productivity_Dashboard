# NEXUS Recommendation Quality

## Purpose

Recommendation quality cannot be represented by a single metric.

A recommendation can be:

- Relevant but difficult
- Easy but low-value
- Urgent but poorly timed
- Accepted but abandoned
- Completed but strategically unimportant

NEXUS therefore evaluates recommendation quality across multiple dimensions.
