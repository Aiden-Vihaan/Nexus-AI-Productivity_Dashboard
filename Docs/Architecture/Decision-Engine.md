# NEXUS Decision Engine

## Overview

The NEXUS Decision Engine determines the strongest next action available to the user based on structured productivity context.

It is a deterministic intelligence component that operates before AI explanation.

The purpose is to prevent NEXUS from delegating core decision-making entirely to a probabilistic language model.

---

# Core Principle

AI should explain and enhance decisions.

It should not be the only mechanism deciding what the user should do.
