# NEXUS Activity Model

## Purpose

The Activity Model provides a structured event stream from which behavioral signals can be calculated.

---

# Activity Event

An activity event represents a meaningful interaction with the productivity system.

Examples:

```text
TASK_CREATED
TASK_STARTED
TASK_PAUSED
TASK_COMPLETED
TASK_REOPENED
TASK_UPDATED
TASK_DEFERRED
PROJECT_CREATED
PROJECT_COMPLETED
FOCUS_SESSION_STARTED
FOCUS_SESSION_ENDED
