# NEXUS Copilot Experience

## Design Vision

The NEXUS Copilot should feel less like opening a chatbot and more like interacting with an intelligent productivity operating system.

---

# Entry Point

The Copilot should be accessible from the primary NEXUS dashboard.

Possible entry:

```text
┌─────────────────────────────────────────────┐
│ NEXUS                                       │
│                                             │
│ What do you need right now?                 │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │ Ask NEXUS anything...                   │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ [Plan my day] [Find my next task]          │
│ [Review my progress] [Start focus session] │
└─────────────────────────────────────────────┘
